# راهنمای قرار دادن فایل‌های فونت طرلان (Tarlan Font)

فونت طرلان یک قلم **تک‌وزن** (دست‌نویس و تیتری) طراحی شده توسط وحید یعقوبلو و توسعه‌یافته توسط امین عابدی است که به صورت تجاری در وب‌سایت فونت ایران عرضه شده است.

این پکیج شامل دو نگارش است:
1. **نسخه اصلی (Tarlan):** دارای ترکیبات هوشمند، اتصالات قلمی و حروف جایگزین (Alternates)
2. **نسخه پایه (Tarlan Base):** بدون ترکیبات هوشمند و با فرم‌های استاندارد و یکنواخت

---

## نام‌گذاری فایل‌ها جهت فعال‌سازی خودکار:

فایل‌های وب‌فونت (`.woff2` و `.woff`) خریداری‌شده از فونت‌ایران را در همین پوشه با نام‌های زیر قرار دهید:

- `tarlan.woff2` (نسخه اصلی - پیشنهاد شده برای عناوین و تیترها)
- `tarlan.woff` (نسخه وب پشتیبان)
- `tarlan-base.woff2` (نسخه پایه)
- `tarlan-base.woff` (نسخه وب پایه پشتیبان)
- `tarlan.ttf` (نسخه اختیاری TrueType)

پیکربندی `@font-face` و کلاس Tailwind به صورت خودکار در پروژه تعریف شده است:
- کلاس Tailwind: `font-tarlan`
- کلاس نسخه پایه: `font-tarlan-base`
- متغیر CSS: `var(--font-tarlan)`
